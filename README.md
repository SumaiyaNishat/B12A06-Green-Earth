#### 1) What is the difference between var, let, and const?
**** var --> Function-scoped, can be redeclared and reassigned.

let --> Block-scoped, can be reassigned but not redeclared.

const --> Block-scoped, cannot be reassigned or redeclared (but object properties can change).

#### 2) What is the difference between map(), forEach(), and filter()? 
*** forEach() --> Do something with each element, no new array.

map() --> Change each element, returns a new array.

filter() --> Pick elements that match a condition, returns a new array.

#### 3) What are arrow functions in ES6?
*** Basically, arrow functions are a shorter, simpler way to write functions in JavaScript.
They are easy to read and automatically use this from the surrounding code.
They are best for small functions and callbacks.

#### 4) How does destructuring assignment work in ES6?
*** Destructuring assignment in ES6 is a way to extract values from arrays or objects and assign them to variables in a clean, concise syntax.

#### 5) Explain template literals in ES6. How are they different from string concatenation?
*** Template literals in ES6 are a way to create strings using backticks (`) instead of quotes, allowing embedded or expressions directly using ${…} and multi-line strings easily.
They also support multi-line strings without extra symbols. In contrast, traditional string concatenation uses quotes and the + operator to join strings and variables, making the code longer and less readable. Template literals provide a cleaner, more readable, and convenient way to work with dynamic or multi-line strings.
